# Weather App

A simple weather app that shows current conditions and a 7-day forecast for any city.

**Live demo:** https://YOUR-USERNAME.github.io/weather-app/

![Screenshot of the weather app](screenshot.png)

## Features

- Search for any city in the world
- Current temperature, conditions, humidity and wind speed
- 7-day forecast with daily highs and lows
- Responsive layout with automatic dark mode
- Clear error messages for unknown cities or network problems

## Built with

- HTML, CSS and JavaScript (no frameworks)
- [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api) and [Forecast API](https://open-meteo.com/en/docs) (free, no API key)

## Run it locally

1. Clone the repo:
   `git clone https://github.com/YOUR-USERNAME/weather-app.git`
2. Open `index.html` in your browser.

## What I learned

- Calling REST APIs with `fetch` and `async/await`
- Handling errors with `try/catch`
- Building a responsive layout with CSS variables
